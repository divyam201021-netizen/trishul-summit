Version of record: this file matches the site as currently built.

--------------------------------------------------------------------------------
 HOW THIS WORKS
--------------------------------------------------------------------------------
* Nothing on this site is invented. Any value that has not been supplied
  renders as an unmistakable placeholder, e.g.  [EVENT DATE - TBD]

* Every item below is edited by an organizer from the admin workspace. No code
  change, redeploy or developer is required. Fill a value and it appears
  instantly everywhere it is used.

* Nothing is lost by leaving a field empty. An empty field is honest; a wrong
  field is not. Fill only what has actually been decided.

* Ticking a box is not enough - the value must exist in the admin workspace.

--------------------------------------------------------------------------------
 WHERE VALUES ARE EDITED
--------------------------------------------------------------------------------
 /admin/settings          Event facts, brand, fees, contact, SEO, legal
 /admin/content           Policies (bodies) and FAQ answers
 /admin/committees        One record per committee
 /admin/schedule          One record per programme session
 /admin/communications    Announcements and email broadcasts
 /admin/staff             Organizer accounts and their roles
 .env                     Environment values (secrets, payment, mail, origin)

 Admin sign-in: /admin/sign-in

  [ ] PAYMENT_SECRET_KEY
  [ ] PAYMENT_WEBHOOK_SECRET

                              Optional bot protection. When absent, the built-in
                              honeypot, rate limit and timing checks are used.

  Until the SMTP values are set, every email is recorded in the database and
  logged instead of being delivered. Until the payment values are set,
  checkout stays disabled and the UI shows [PAYMENT DETAILS - TBD].
  Never commit real secrets to version control.

================================================================================
 WHAT NEVER GETS INVENTED (BY DESIGN)
================================================================================
The platform will not create, guess or imply any of the following, and no
setting can make it do so:

  - Dates, times or time zones that were not supplied
  - Fees, currency or payment details before they are confirmed
  - Seat counts, "only N left" or registration countdowns
  - Testimonials, endorsements, partner or sponsor logos
  - Attendance numbers, delegate statistics or growth claims
  - Committee names, agendas or chair names
  - FAQ answers, policy text or any legal wording
  - Session times without an explicit time zone

Empty values remain visibly empty until an organizer fills them in.
